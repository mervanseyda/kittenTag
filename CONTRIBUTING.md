# Contributing to kittenTag

Thanks for helping improve kittenTag.

## Before opening an issue

- Search existing issues first.
- Include the macOS version, Mac architecture, kittenTag version, and audio format.
- Describe what you expected, what happened, and whether the failure occurred while reading, editing, or saving.
- Never upload private or copyrighted audio. Create a short disposable reproduction when possible.

## Pull requests

- Keep changes focused and explain the user-facing reason for them.
- Preserve the offline-first product direction.
- Add or update tests for metadata, artwork, filename, and save-path changes.
- Run `swift test` before submitting.
- Do not commit build products, signing credentials, certificates, notarization passwords, or personal media.
