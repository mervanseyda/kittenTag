# kittenTag roadmap

kittenTag 1.0 is a free, open-source, offline macOS metadata editor. The first priority is reliability, format compatibility, and a small native interface.

## 1.0 release

- [x] Batch metadata editing
- [x] Embedded artwork editing and optimization
- [x] Filename-to-tags and tags-to-filename previews
- [x] Search, sorting, customizable columns, and CSV export
- [x] English and Turkish localization
- [x] Apple Silicon and Intel support on macOS 13 or later
- [x] Automated metadata, artwork, rename rollback, localization, and integrity tests
- [x] Signed and notarized direct-download packaging
- [x] Remove the public-beta expiration and licensing restrictions
- [x] Publish the source under the MIT License

## Possible future work

- In-app diagnostic information and a support link
- Find and replace, including optional regular expressions
- Automatic track and disc numbering
- Additional metadata fields based on real user reports
- Batch artwork export
- Playlist and configurable export templates
- Optional update checking
- Additional formats only after dedicated read/write integrity tests

## Intentionally out of scope

- Audio playback or transcoding
- Automatic title-case or letter-case rewriting
- Accounts, cloud synchronization, license activation, or telemetry
- MusicBrainz, Discogs, or other online metadata lookup
- Feature parity with every advanced tagging suite
